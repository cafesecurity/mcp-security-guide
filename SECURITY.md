# Security policy

## The example server

`examples/ask-trevor/` is a teaching example. It is not meant to be deployed as is, and it uses a local test token issuer that must never be used in production.

If you find a vulnerability in the example, please report it privately through GitHub's "Report a vulnerability" button on this repository (Security tab), not in a public issue. We'll acknowledge it as soon as we can, typically within a week.

## The guide's advice

If you think a recommendation in the guide is wrong in a way that could lead someone to build something insecure, open an issue with the "Correction" template. These are fixed first.
